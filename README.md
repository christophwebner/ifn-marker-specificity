# ifn-marker-specificity

[![DOI](https://zenodo.org/badge/1455806703.svg)](https://doi.org/10.5281/zenodo.24175394)

Analysis code for the article **"A specificity test for single-gene interferon-associated immune markers in gynecological and breast cancers"** (Ebner C, Hackl H, Marth C, Zeimet AG, Wieser V; Medical University of Innsbruck).

The analysis is entirely *in silico* and uses only public data. For each gene, cohort and immune read-out it compares the raw Spearman correlation with the partial correlation after removal of a leave-one-out score of the Reactome Interferon Signaling pathway. The test is calibrated against expression-matched non-interferon genes and synthetic genes, applied to thirteen published markers and to the whole pathway, and repeated in three independent cohorts.

## Repository layout

```
code/            analysis scripts (run in the order below)
data/            input files shipped with the repository
run_all.R        runs the complete analysis
requirements.R   installs the required R packages
sessionInfo.txt  R session of the run that produced the published results
```

`output/` is created on the first run and holds the downloaded data (`output/cache/`), intermediate results (`output/intermediate/`) and all figures, tables and supplementary data of the article (`output/paper/`).

## How to run

From the repository root:

```bash
Rscript run_all.R
```

`run_all.R` installs missing packages (`requirements.R`), runs the six analysis scripts in order, each in a fresh R session, and writes `output/run_log.txt` and `output/sessionInfo.txt`. The first run downloads the expression data from cBioPortal and the Gene Expression Omnibus (about 160 MB) and took about 9 minutes on an Apple silicon Mac. Later runs use the cache.

## Scripts

| Order | Script | Content | Article output |
|---|---|---|---|
| shared | `code/setup.R` | paths, cache for downloads | |
| shared | `code/gene_sets.R` | interferon gene sets from MSigDB | Supplementary Data S1 |
| 1 | `code/01_threshold_and_score_construction.R` | whole interferon pathway vs. expression-matched genes, empirical threshold, six constructions of the pathway score | Figure 4; Supplementary Figures S2, S4; Supplementary Tables S6, S10 |
| 2 | `code/02_specificity_test_tcga.R` | specificity test in four TCGA cohorts, controls, confounder adjustment, classification, threshold sensitivity | Figures 1, 2; Table 1; Supplementary Figures S1, S3; Supplementary Tables S2 to S5 |
| 3 | `code/03_external_validation.R` | METABRIC, CPTAC endometrial carcinoma, GSE9891 | Figure 5; Supplementary Table S7 |
| 4 | `code/04_calibration_simulation.R` | calibration with synthetic genes | Figure 3; Supplementary Table S8 |
| 5 | `code/05_proliferation_control.R` | interferon pathway vs. E2F proliferation program | Supplementary Figure S5; Supplementary Tables S2 (proliferation gene sets), S9 |
| 6 | `code/06_figures_and_tables.R` | all figures, tables, supplementary data and key numbers | `output/paper/` |

Script 01 writes the empirical threshold used by scripts 02, 04, 05 and 06. Supplementary Table S1 (literature sources of the markers) is not generated by the code.

## Data

- **TCGA PanCancer Atlas** (endometrial, ovarian, cervical and breast carcinoma; studies `ucec_tcga_pan_can_atlas_2018`, `ov_tcga_pan_can_atlas_2018`, `cesc_tcga_pan_can_atlas_2018`, `brca_tcga_pan_can_atlas_2018`), **METABRIC** (`brca_metabric`) and **CPTAC endometrial carcinoma** (`uec_cptac_gdc`): downloaded from cBioPortal with `cBioPortalData`.
- **GSE9891** (ovarian carcinoma): downloaded from the Gene Expression Omnibus with `GEOquery`.
- **Gene sets**: MSigDB via `msigdbr` (Reactome Interferon Signaling, Hallmark interferon-gamma and interferon-alpha response, Hallmark E2F targets).
- `data/aran_2015_purity.xlsx`: tumor purity estimates, Supplementary Data 1 of Aran D, Sirota M, Butte AJ. Systematic pan-cancer analysis of tumour purity. Nat Commun 2015;6:8971 (https://doi.org/10.1038/ncomms9971), licensed under CC BY 4.0.
- `data/background_gene_pool.csv` and `data/matched_gene_pairs.csv`: the fixed pool of 2000 non-interferon genes and the expression-matched gene pairs used in the article (Supplementary Data S3 and S2).

## Software

R 4.6.1 with cBioPortalData 2.24.0, GSVA 2.6.14, msigdbr 26.1.1, GEOquery 2.80.0, Biobase 2.72.0, dplyr 1.2.1, tidyr 1.3.2, ggplot2 4.0.3, ggrepel 0.9.8, patchwork 1.3.2, janitor 2.2.1 and readxl 1.6.0. The complete session is in `sessionInfo.txt`. Other versions of msigdbr can contain different gene sets. All resampling and simulation use the random seed 42.
